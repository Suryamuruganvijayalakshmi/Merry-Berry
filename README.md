## 🎬 Cinematic Scroll Experience

The website transforms the Merry Berry product animation into a **scroll-controlled timeline**:

- **User Scroll = Video Timeline:** Scrolling down advances the animation frame-by-frame; scrolling up smoothly reverses it without video seek stutter.
- **HTML5 Canvas Scrubbing:** Uses pre-decoded 240 WebP frames with sub-pixel interpolation (`lerp`) and `requestAnimationFrame` for smooth 60fps performance on desktop and mobile.
- **5 Synchronized Phases:**
  1. **Phase 01 · Clean Product:** Full-screen pure white hero with centered photorealistic tub and minimal branding.
  2. **Phase 02 · Brand Reveal:** Background shifts into rich royal purple with oversized editorial typography.
  3. **Phase 03 · Artisanal Splash & 3D Berries:** Product tilts with an explosive ice cream splash and floating 3D berries.
  4. **Phase 04 · Color Symphony:** Dynamic wave transitions across berry pink, mango gold, and sweet cream.
  5. **Phase 05 · Final Brand Moment:** Grand brand reveal with the 4.9★ rating badge leading seamlessly into the main cafe website.

## 🌟 Features

- **Sticky Glassmorphic Navbar:** Revealing naturally as the hero completes, with full navigation and quick-order tray button.
- **About the Cafe:** Editorial spread with authentic cafe photography and core quality pillars.
- **Interactive Flavours ("What's Your Mood?"):** 3D hover-zoom cards for Strawberry, Blueberry, Chocolate, Vanilla, Mango, and Falooda with mood filter pills.
- **Signature Menu:** Categorized menu with spotlight showcase for the **Classic Vanilla Falooda**.
- **Cafe Experience:** Horizontal parallax scroller showcasing authentic cafe moments and customer smiles.
- **Customer Reviews:** Auto-advancing review carousel featuring verified 4.9★ Google diner feedback.
- **Location & Custom Interactive Map:** Detailed address (*Ayana Plaza, opp. Golden Mahal, Solar Pirivu, Solar, Erode*) with custom-styled dark berry road grid and pulsing cafe pin.
- **Interactive Order Drawer:** Cart tray supporting Takeaway vs. Dine-in (with table number) and direct WhatsApp order dispatch to `082485 15955` with confetti celebration.
- **Mobile Optimized:** Touch swipeable pills, large vertical hero composition, and responsive drawer navigation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Suryamuruganvijayalakshmi/Merry-Berry.git

# Navigate into project directory
cd Merry-Berry

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
